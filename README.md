# MindBridge Releases

Public installer downloads for MindBridge beta and stable builds.

Source code stays in the private repo `ungameproductor/mindbridge`.

## Current beta

**[v1.9.0-beta.2](https://github.com/ungameproductor/mindbridge-releases/releases/tag/v1.9.0-beta.2)** — second closed beta. Seven days start the first time this build is opened, on Mac and Windows. A computer that already ran an earlier beta gets a new 7-day period; chats and files stay on the computer.
